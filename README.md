# 전현우 · Full-stack Engineer

제품 문제를 빠르게 구조화하고, 웹·API·AI 기능을 실제 서비스로 연결하는 개발자입니다. TypeScript와 React/Next.js를 중심으로 사용자 경험을 만들고, Node.js·Cloudflare·PostgreSQL 기반의 백엔드와 배포 환경까지 함께 설계합니다.

## What I build

- **제품 중심 웹 서비스** — 인증, 파일 공유, 커뮤니티, 예약과 같은 사용자 흐름을 React·Next.js로 구현합니다.
- **확장 가능한 서버와 데이터 계층** — Node.js, Express, PocketBase, PostgreSQL, Prisma, Drizzle ORM을 사용해 API와 데이터 모델을 설계합니다.
- **AI·데이터 활용 기능** — Python, PyTorch, 생성형 AI API를 활용해 텍스트·영상·추천 문제를 제품 기능으로 연결합니다.
- **운영 가능한 배포 환경** — Vercel, Cloudflare Workers/R2, Ubuntu, GitHub Actions 기반으로 배포와 자동화를 다룹니다.
